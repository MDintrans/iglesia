# Iglesia Misionera Pentecostal Peralillo

Sitio web estático de la Iglesia Misionera Pentecostal de Peralillo.

## Sitio publicado

[https://mdintrans.github.io/iglesia/](https://mdintrans.github.io/iglesia/)

## Estructura

- `index.html`: página principal.
- `styles.css`: estilos y diseño responsive.
- `script.js`: navegación, animaciones y enlaces configurables.
- `assets/`: imágenes del sitio.

GitHub Pages publica automáticamente la raíz de la rama `main` mediante la opción **Deploy from a branch**.
